# Abdul Khaliq — Frontend Developer Portfolio

Responsive React + TypeScript portfolio built with Vite, Tailwind CSS, and Framer Motion.

## Run locally
```bash
npm install
npm run dev
```

## Build
```bash
npm run build
```

## Before publishing
- The original template portrait URL is retained in `src/sections/HeroSection.tsx`. Replace it with the final smiling avatar image when available.
- Add your phone number and email address in `src/sections/ContactSection.tsx`.
- Replace the GitHub — Coming Soon placeholders in `src/sections/ProjectsSection.tsx` with repository URLs later.
- The four live project website links are already included.
